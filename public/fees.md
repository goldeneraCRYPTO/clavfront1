# Fees

## How fees are claimed (Bags)

Bags provides two ways to claim fees:

### 1) Dev Dashboard

- Go to https://dev.bags.fm and log in.
- View claimable fees in the Partner Key table.
- Click **Claim** and sign with your wallet.

### 2) SDK (programmatic)

- Requires a Bags API key and a Solana wallet private key.
- Your wallet must have enough SOL to pay transaction fees.

## Notes

- Claiming uses on-chain transactions; keep SOL for fees.
- API requests to Bags require `x-api-key`.

For full details, follow Bags docs:
- Claim partner fees: https://docs.bags.fm/how-to-guides/claim-partner-fees
- Claim token fees: https://docs.bags.fm/how-to-guides/claim-fees
- API authentication: https://docs.bags.fm/
